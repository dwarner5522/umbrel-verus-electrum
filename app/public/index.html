About this server

This is your own Electrum server for Verus (VRSC). Lite wallets that support custom Electrum servers can use it instead of a public one, so your addresses and balances are only looked up on your own node.

It serves plain TCP on your local network. It is not encrypted, so don't expose this port to the internet.
